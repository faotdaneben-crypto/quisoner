## 📦 DATABASE SCHEMA (8 Tables)

1. **users** - Admin accounts (bcrypt hashed passwords)
2. **services** - Service units (Pendaftaran, IGD, Rawat Jalan, etc.)
3. **questions** - 9 survey questions
4. **answer_options** - Answer choices with scores (1-4)
5. **respondents** - Patient demographic data
6. **responses** - Individual question answers
7. **suggestions** - Patient feedback with status tracking
8. **audit_logs** - Admin activity log

## 🚀 HOW TO RUN (Windows)

### Option 1: Automated Setup (Recommended)
```cmd
cd C:\Users\Digitalisasi\quisoner\packages\surveys-app
scripts\setup-windows.bat
```

This will:
1. Delete old node_modules
2. Install npm packages
3. Create .env file from template
4. Generate Prisma client
5. Push schema to database
6. Seed initial data

### Option 2: Manual Steps

**Step 1: Install Dependencies**
```cmd
cd packages\surveys-app
npm install
```

**Step 2: Configure Environment**
```cmd
copy .env.example .env
```

Edit `.env` and add your PostgreSQL connection:
```
DATABASE_URL="postgresql://username:password@localhost:5432/surveys_db"
JWT_SECRET=change-this-to-random-string
```

**Step 3: Setup Database**
```cmd
npm run db:generate
npm run db:push
npm run db:seed
```

**Step 4: Run Development Server**
```cmd
npm run dev
```

## 🔧 TROUBLESHOOTING

**Issue: "Cannot find module"**
Solution: Run `npm install` again

**Issue: Database connection error**
Solution: Check DATABASE_URL in .env, ensure PostgreSQL is running

**Issue: Migration failed**
Solution: Run `npm run db:generate` first, then `db:push`

**Issue: Can't login as admin**
Solution: Re-run `npm run db:seed` to reset credentials

**Issue: Port 3001 already in use**
Solution: Edit package.json to change port, or kill existing process
